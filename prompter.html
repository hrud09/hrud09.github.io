Prompter: AI Prompt Manager

Prompt Engineering Flutter Multi-Version History 100% On-Device & Private

A personal offline library and workspace for organizing, engineering, and versioning AI prompts. Structure prompts for ChatGPT, Midjourney, Claude, and LLMs with custom input placeholders, reference images, multi-version history tracking, and tag-based categorization—stored 100% locally.

GitHub Repository Support & Feedback

Core Prompt Engineering Capabilities

Multi-Version Iteration History

Track prompt changes over time. Branch, compare revisions, and revert to previous high-performing prompt iterations with ease.

Dynamic Variable Placeholders

Define dynamic input fields such as {topic}, {tone}, and {audience} to generate customized prompts on demand with a fast form fill interface.

Reference Image Attachments

Attach reference style images, character model sheets, and prompt output comparisons directly to prompts with local on-device image storage.

Custom Groups & Tag Organization

Organize prompts into color-coded categories (e.g., Coding, Copywriting, Midjourney, Roleplay) with multi-tag filtering.

Lightning-Fast Instant Search

Full-text search powered by SQLite searches prompt body text, variables, tags, and notes instantly as you type.

100% On-Device & Private

Your proprietary AI prompts, system instructions, and engineering assets never touch external servers or third-party databases.

Technical Specifications & Details
